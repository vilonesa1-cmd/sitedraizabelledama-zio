# Izabelle Damázio Schmidt — site institucional

Landing page estática, responsiva e mobile-first. O site usa HTML, CSS e JavaScript no arquivo `index.html`. As fotos do carrossel de procedimentos também estão embutidas no próprio HTML, então continuam aparecendo mesmo quando o arquivo é aberto sozinho. As pastas `images/` e `assets/` acompanham o pacote como cópia dos arquivos de imagem. Não precisa de etapa de build.

## Conteúdo do site

- Apresentação da profissional e dos cuidados.
- Carrossel único com registros de facetas em resina e toxina botulínica, alternados, com navegação por arraste, setas e contador.
- Simulador de avaliação em cinco etapas, com envio do resumo pelo WhatsApp.
- Informações de contato, endereço, horário de atendimento, perguntas frequentes e mapa.
- Layout responsivo, acessibilidade por teclado e respeito à preferência por movimento reduzido.

## Publicar com GitHub Pages

1. Envie o conteúdo desta pasta para a raiz de um repositório GitHub.
2. No repositório, acesse **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**, selecione a branch desejada e a pasta **/(root)**.
4. Salve e aguarde a publicação do endereço indicado pelo GitHub.

Mantenha `index.html`, `images/` e `assets/` juntos na raiz do repositório.
